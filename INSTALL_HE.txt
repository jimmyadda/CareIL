CareIL - Bilingual Content and Checkout Workflow Update
=======================================================

התקנה:
1. בצעו Commit או גיבוי לשינויים הקיימים.
2. חלצו את תוכן ה-ZIP ישירות לתיקיית השורש של CareIL.
3. אשרו החלפת קבצים בעלי אותו שם.
4. הריצו: python -m unittest tests.test_billing_flow -v
5. בצעו Commit, Push והמתינו לפריסה ב-Railway.

העדכון כולל:
- מסלולים חודשיים ושנתיים: Basic 59/590, Professional 89/890.
- כפתורי רכישה חודשית ושנתית בעמוד המסלולים.
- עמוד Checkout דו-לשוני שנראה כחלון תשלום.
- טבלאות הזמנות ומנויים ומעבר תשלום idempotent.
- מסכי המתנה, הצלחה וכישלון.
- הכנת קישור חד-פעמי להגדרת חשבון ומיילים ללקוח ולבעלים.
- ביטול זרימת בקשת הגישה מכפתורי האתר הציבורי והפניה למסלולים.
- כל עדכון התוכן הדו-לשוני: 7 מאמרים, FAQ באנגלית וניווט מעודכן.
